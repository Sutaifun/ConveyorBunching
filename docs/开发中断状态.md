## 自检覆盖了什么

`npm run check` 现在会挡住这些错：同种子两次结果不一致（非确定性）、换种子结果不变（种子没接上）、均匀排布 CV≠0、全挤一点 CV≠√(K−1)、**空店却出现服务或结团**（核凭空造聚集）、结团时间随阈值非单调。

## 必须保住的结论

数字的单一出处是**指导文第 4.7 节**，不在这里重复维护。三条骨干：

1. 一顿饭的长度刚好够结团走完全程——16 分钟越过「随便乱扔」，25 分钟半程，90 分钟时六把壶挤在圆周 2% 的弧段里。
2. 需求率只决定多快，不决定会不会：60 倍需求率变化 → 18 分钟对 281 分钟，终点一样。
3. 姜片（K=1）的热座效应没有空间范围，隔一桌就归零。这是「结团至少要两件东西」的反证。
