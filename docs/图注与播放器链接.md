# 图注草稿与播放器链接

> 本文为站长写小品正文提供配套：每张图的图注草稿、播放器参数、复现链接。数字的单一出处是 [`科学小品指导.md`](科学小品指导.md) 第 4.7 节。

---

## 播放器入口

| 环境 | 路径 |
|---|---|
| 线上（暂未开放） | `/widgets/kettles` + query（`VITE_FEATURE_WIDGETS` 未开） |
| 本地预览 | `npm run play` 后访问根路径 + 同一 query |

## Query 参数

| 键 | 含义 | 旗舰值 |
|---|---|---|
| `k` | 壶数 | 6 |
| `seed` | 随机种子 | 20260830 |
| `interval` | 每人多久加一次汤（分钟） | 10 |
| `tau` | 倒汤时间（秒） | 10 |
| `loop` | 一圈时长（秒） | 450 |
| `mins` | 预演时长（分钟） | 180 |
| `seats` | 座位数 | 40 |
| `t` | 打开时停在第几分钟 | 可选 |

## fig1 时空图

**图注草稿：**

> 开餐时六把汤壶均匀放置在传送带上（上栏 0 分钟处）。随着顾客取用，壶与壶的间距开始崩坏；约 50 分钟后全部挤成一条窄带。下栏是扣掉传送带转动后的「共动视角」：没被碰过的壶是水平线，被拿一次就往下掉一截。

**播放器链接：**

基础 query（旗舰开餐 scene-a）：

```
?k=6&seed=20260830&interval=10&tau=10&loop=450&mins=180&seats=40
```

推荐观察点：

| 时刻 | 链接 | 说明 |
|---|---|---|
| t=0 | `?k=6&seed=20260830&interval=10&tau=10&loop=450&mins=180&seats=40&t=0` | 开餐，均匀排布 |
| t=16 | `?k=6&seed=20260830&interval=10&tau=10&loop=450&mins=180&seats=40&t=16` | 刚越过「随便乱扔」 |
| t=25 | `?k=6&seed=20260830&interval=10&tau=10&loop=450&mins=180&seats=40&t=25` | 结团走完一半 |
| t=30 | `?k=6&seed=20260830&interval=10&tau=10&loop=450&mins=180&seats=40&t=30` | 明显可见结团 |
| t=90 | `?k=6&seed=20260830&interval=10&tau=10&loop=450&mins=180&seats=40&t=90` | 一顿饭结束，六壶挤在 2% 弧段 |

## fig2 结团进程

**图注草稿：**

> 结团指数从 0（均匀）向 1（完全挤在一起）攀升。16 分钟越过「随便乱扔」的水平，25 分钟走完一半，吃完一顿饭前早已挤好。虚线是 90 分钟（一顿饭）和 180 分钟（一个晚市）的参考位置。

**播放器链接：**

同 fig1，使用旗舰 query。播放器显示的「结团指数」数字与此图纵轴一致。

```
?k=6&seed=20260830&interval=10&tau=10&loop=450&mins=180&seats=40
```

## fig3 多久才结团

**图注草稿：**

> 横轴是顾客加汤的间隔（越靠左越忙），纵轴是结团走完一半需要多久。三条曲线对应不同倒汤时长。需求再稀疏，终点仍是同一个——问题只是多快，不是会不会。

**播放器说明：**

此图是多种子扫描的均值曲线，**播放器无法整图复现**。可用旗舰点体验单次结团：

```
?k=6&seed=20260830&interval=10&tau=10&loop=450&mins=180&seats=40&t=25
```

## fig4 壶的数量

**图注草稿：**

> 左图：壶越多，归一化结团指数越低，但裸变异系数反而升高——因为上限 √(K−1) 本身在涨。右图：平均等待时间随壶数单调下降。两张并排是为了说明「指数降、等待也降」并不矛盾。

**播放器说明：**

此图是多种子扫描，**播放器无法整图复现**。可链回旗舰点，或改 `k` 参数感受不同壶数：

| 壶数 | 链接 |
|---|---|
| K=6（旗舰） | `?k=6&seed=20260830&interval=10&tau=10&loop=450&mins=180&seats=40&t=90` |
| K=3 | `?k=3&seed=20260830&interval=10&tau=10&loop=450&mins=180&seats=40&t=90` |
| K=12 | `?k=12&seed=20260830&interval=10&tau=10&loop=450&mins=180&seats=40&t=90` |

## fig5 姜片对照

**图注草稿：**

> 左图：一盒姜片（K=1）的等待分布几乎摊平在一整圈上，中位 313 秒、九成 492 秒。右图：把第 12 桌的需求放大八倍后，该桌停留时长增加 40 秒，而隔一桌起增量归零——热座效应没有空间范围。这说明结团至少需要两件东西互相让路。

**播放器链接：**

姜片场景：

```
?k=1&seed=ginger-1&interval=15&tau=5&loop=450&mins=180&seats=40
```

注：「热座对照」（第 12 桌 λ×8）是 CLI 扫参跑的，播放器目前未暴露单桌需求倍率。

## fig6 服务员巡台

**图注草稿：**

> 每隔一段时间把壶重新均匀摊开，等价于公交的「到站故意等一等」。不重整时结团指数 0.92、平均等待 238 秒；每 30 分钟重整一次，指数降到 0.36、等待降到 75 秒；每 10 分钟则 0.18 / 53 秒。完美均匀的理论下限是 37.5 秒。代价曲线上凸：压掉一半结团就能拿回大部分等待。

**播放器说明：**

此图是对不同 `resetPeriod` 的扫描，**播放器目前无 resetPeriod 参数**。可链回旗舰点体验「不重整」的情况：

```
?k=6&seed=20260830&interval=10&tau=10&loop=450&mins=180&seats=40&t=90
```

上述等待数字（238 秒 → 75 秒 → 53 秒）出自指导文第 4.7 节。
