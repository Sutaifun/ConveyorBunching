# 图注草稿与播放器链接

> 本文为站长写小品正文提供配套：每张图的图注草稿、播放器参数、复现链接。数字的单一出处是 [`科学小品指导.md`](科学小品指导.md) 第 4.7 节。
>
> 口径（2026-10）：fig2 是种子 `20260830` 这一次；fig3 / fig4 / fig6 是种子 1–8 的均值。倒汤 10 秒、8 小时内，间隔 2→120 分钟都越过半程，但后一半结团指数约 0.98→0.59，不是「终点一样」。播放器 t=90 的累计平均等待约 178 秒，不是后一半的 238 秒。

## 播放器入口

| 环境 | 路径 |
|---|---|
| 线上（暂未开放） | `/widgets/kettles` + query（`VITE_FEATURE_WIDGETS` 未开） |
| 本地预览 | `npm run play` 后访问根路径 + 同一 query |

## Query 参数

| 键 | 含义 | 旗舰值 |
|---|---|---|
| `k` | 壶数 | 6 |
| `seed` | 随机种子 | 20260830 |
| `interval` | 每人多久加一次汤（分钟） | 10 |
| `tau` | 倒汤时间（秒） | 10 |
| `loop` | 一圈时长（秒） | 450 |
| `mins` | 预演时长（分钟） | 180 |
| `seats` | 座位数 | 40 |
| `t` | 打开时停在第几分钟 | 可选 |

## fig1 时空图

单种子（`20260830`）。播放器可以复现这一次开餐。

**图注草稿：**

> 开餐时六把汤壶均匀放置在传送带上（上栏 0 分钟处）。随着顾客取用，壶与壶的间距开始崩坏。下栏是扣掉传送带转动后的「共动视角」：没被碰过的壶是水平线，被拿一次就往下掉一截。这一次开餐里，50 分钟的覆盖弧约 7.8%（结团指数约 0.91），约 2.2% 出现在 90 分钟——不是 50 分钟后就全部挤成一条窄带。

**播放器链接：**

基础 query（旗舰开餐 scene-a）：

```
?k=6&seed=20260830&interval=10&tau=10&loop=450&mins=180&seats=40
```

推荐观察点（都是种子 `20260830` 这一次）：

| 时刻 | 链接 | 说明 |
|---|---|---|
| t=0 | `?k=6&seed=20260830&interval=10&tau=10&loop=450&mins=180&seats=40&t=0` | 开餐，均匀排布 |
| t=16 | `?k=6&seed=20260830&interval=10&tau=10&loop=450&mins=180&seats=40&t=16` | 刚越过「随便乱扔」（指数约 0.37，参照约 0.36） |
| t=25 | `?k=6&seed=20260830&interval=10&tau=10&loop=450&mins=180&seats=40&t=25` | 半程首次越过约在 24.3 分钟；这一帧指数约 0.48，还没稳住在一半以上 |
| t=30 | `?k=6&seed=20260830&interval=10&tau=10&loop=450&mins=180&seats=40&t=30` | 明显可见结团 |
| t=90 | `?k=6&seed=20260830&interval=10&tau=10&loop=450&mins=180&seats=40&t=90` | 一顿饭结束。这一次弧长约 2.2%，累计平均等待约 178 秒，结团指数约 0.97。不是后一半的 238 秒 |

## fig2 结团进程

**单种子曲线**（场景 A，种子 `20260830`），不是 fig3 在「10 分钟、倒汤 10 秒」那一点的 8 种子均值（半程均值约 31.8 分钟）。

**图注草稿：**

> 结团指数从 0（均匀）向 1（完全挤在一起）攀升。这是种子 20260830 的一条曲线。这一次：16 分钟越过「随便乱扔」，半程首次越过约在 24.3 分钟（图题可写成约 25 分钟）。竖虚线只有一条，在一顿饭 90 分钟；180 分钟是横轴终点，不是第二条竖虚线。横虚线是「随便乱扔」（约 0.36）和上限 1。

**播放器链接：**

同 fig1，使用旗舰 query。播放器显示的「结团指数」数字与此图纵轴一致，但是这一次开餐，不是 8 种子均值。

```
?k=6&seed=20260830&interval=10&tau=10&loop=450&mins=180&seats=40
```

t=25 不要写成「结团走完一半」：该帧指数约 0.48。首次越过 0.5 约在 24.3 分钟。

## fig3 多久才结团

**图注草稿：**

> 8 个种子的均值。横轴是顾客加汤的间隔（越靠左越忙），纵轴是结团走到一半需要多久。倒汤 10 秒、8 小时内，间隔从 2 分钟到 120 分钟都越过半程（约 18 分钟对 281 分钟），但后一半结团指数约 0.98→0.59，不是同一个终点。一顿饭内能否到半程看忙闲：间隔 30 分钟仍在饭前（约 78 分钟），间隔 45 分钟则约 136 分钟，落在绿线之上。倒汤 5 秒的冷清端有种子在 8 小时内没到半程（间隔 90 分钟 3 个、120 分钟 4 个），那些点的均值把没到的种子丢掉了，会偏快；不要把灰线最右端读成「平均 353 / 379 分钟就到半程」。旗舰点上，种子 20260830 这一次的半程约 24.3 分钟，图上画的是种子 1–8 的均值约 31.8 分钟。

**播放器说明：**

此图是多种子扫描的均值曲线，**播放器无法整图复现**。可用旗舰点体验单次结团。t=25 显示的指数约 0.48，半程首次越过约在 24.3 分钟：

```
?k=6&seed=20260830&interval=10&tau=10&loop=450&mins=180&seats=40&t=25
```

## fig4 壶的数量

**图注草稿：**

> 种子 1–8 的均值。左图：壶越多，归一化结团指数越低（K=6 / 12 / 20 约 0.92 / 0.77 / 0.60），但裸变异系数反而升高——因为上限 √(K−1) 本身在涨。右图：平均等待随壶数下降（约 238→166→98 秒；238 是后一半均值，不要写成 239）。两张并排是为了说明「指数降、等待也降」并不矛盾。

## fig5 姜片对照

**图注草稿：**

> 左图：一盒姜片（K=1）的等待分布几乎摊平在一整圈上，中位 313 秒、九成 492 秒。右图：把第 12 桌的需求放大八倍后，该桌停留时长增加 40 秒。相邻座位增量为 0；更远只有 ±5 秒量级，没有连成一片的空间尾巴。全店总停留从 1730 秒到 1775 秒，多出的约 45 秒里约 40 秒在热座。这说明结团至少需要两件东西互相让路。

**播放器链接：**

姜片场景：

```
?k=1&seed=ginger-1&interval=15&tau=5&loop=450&mins=180&seats=40
```

注：「热座对照」（第 12 桌 λ×8）是 CLI 扫参跑的，播放器目前未暴露单桌需求倍率。

## fig6 服务员巡台

**图注草稿：**

> 种子 1–8 的均值。每隔一段时间把壶重新均匀摊开，等价于公交的「到站故意等一等」。不重整时结团指数 0.92、后一半平均等待 238 秒；每 30 分钟重整一次，指数降到 0.36、等待降到 75 秒；每 10 分钟则 0.18 / 53 秒。完美均匀的理论下限是 37.5 秒。代价曲线上凸：压掉一半结团就能拿回大部分等待。

**播放器说明：**

此图是对不同 `resetPeriod` 的扫描，**播放器目前无 resetPeriod 参数**。可链回旗舰点体验「不重整」的这一次开餐：

```
?k=6&seed=20260830&interval=10&tau=10&loop=450&mins=180&seats=40&t=90
```

这条链接在 t=90 显示的是从开餐累计的平均等待约 **178 秒**、结团指数约 **0.97**。不要把它写成图上的后一半均值 238 秒。238→75→53 秒出自指导文第 4.7 节，是种子 1–8 的后一半均值。
